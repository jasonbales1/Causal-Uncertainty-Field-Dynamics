## Quick Start & Reproducibility

### Requirements & Installation
Requires Python >= 3.10 with `numpy`, `scipy`, and `matplotlib`:
```bash
git clone https://github.com/jasonbales1/Causal-Uncertainty-Field-Dynamics.git
cd Causal-Uncertainty-Field-Dynamics
pip install -r requirements.txt
```

### Execute Complete 40-Suite Verification & 16 Referee Gates
```bash
python -B run_all_tests.py   # Runs all 40 suites, 16 gates, and generates output/*
python -B export_latex.py    # Exports Overleaf/arXiv-ready .tex manuscripts to latex/
```
